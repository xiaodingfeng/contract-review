# 众安合同审核 POC 知识库资料清单

## 一、资料提交边界

POC 审查仅使用众安确认提供的合同范本、法律法规、司法案例和合同审查要点。系统不使用模型记忆补充依据，也不通过公网搜索补齐缺失内容。

真实合同及知识库源文件统一放在部署环境的 `local-knowledge/` 或内网文件存储中。该目录已被 Git 忽略，不上传 GitHub。

## 二、合同范本库

请按咨询类、施工类、设计类、服务类、采购类分别准备。每份范本需附以下信息：

- 范本名称
- 合同品类及具体业务场景
- 适用公司或业务板块
- 适用国家／地区及约定管辖法律
- 中文、英文或双语版本
- 当前版本号、生效日期、是否仍在使用
- 标准条款正文及附件清单
- 业务及法务确认人

POC 建议每个品类至少提供 1 至 2 份正式范本，优先覆盖实际试审合同对应的业务场景。

## 三、法律法规库

每份法规资料至少包含：

- 国家／地区及司法管辖区
- 法规正式名称和原文语言
- 发布机关及官方来源
- 公布日期、施行日期、当前效力状态
- 条款编号和完整原文
- 中文翻译版本及翻译来源（如适用）
- 内部法务确认日期和确认人

境外法规必须按司法管辖区隔离入库，不得把不同国家或地区的规则混在同一个检索范围中。没有可靠官方来源或内部法务确认的材料，只能标记为待核验，不作为自动修正依据。

## 四、司法案例库

每个案例至少包含：

- 国家／地区、法院名称和案号
- 裁判日期及案件状态
- 争议焦点
- 案件事实摘要
- 裁判逻辑
- 裁判结果
- 可用于合同审核的结论
- 官方或内部认可来源

案例不得只保存二手摘要。缺少裁判原文或可靠来源的案例不进入正式依据库。

## 五、合同审查要点库

每条审查要点应采用统一字段：

- 合同品类
- 业务场景
- 适用国家／地区
- 审查维度
- 必备关键字或等同语义
- 必备条款要素
- 标准条款原文
- 缺失或相悖时的判断规则
- 对应范本、法规或案例依据
- 可直接替换的修正文本
- 问题分类：范本差异／合规瑕疵／计算错误／文本错误

成本维度至少覆盖付款节点、付款比例、工期或服务周期、材料价格调差、质保期及质保责任。法务维度至少覆盖双方权利义务、违约责任、逾期责任、窝工责任、免责条款和终止解除。

## 六、试审合同样本

每个品类建议准备 2 至 3 份脱敏合同，包括一份相对规范合同和一份问题较多合同。每份样本应标注：

- 预期合同品类
- 审查立场
- 适用国家／地区和约定管辖法律
- 已知问题清单
- 期望修改结果
- 是否包含报价表、结算表、费用表或计量表
- 是否允许作为演示数据长期保留

当前基线支持可复制文字的 DOCX 和 PDF。扫描 PDF、XLSX 公式复算及复杂附件表格属于下一阶段能力，POC 样本中如包含此类文件请单独标记。

## 七、POC 验收样本建议

首轮可先提供以下最小集合：

- 五类合同各 1 份标准范本
- 五类合同各 1 份脱敏试审合同
- 每类 20 至 30 条核心审查要点
- 与首轮合同直接相关的现行法规原文
- 每类 2 至 5 个具有代表性的真实案例

先用小而可靠的数据闭环验证“品类识别—范本匹配—依据检索—四模块报告—修改文案”，再扩充完整知识库。
